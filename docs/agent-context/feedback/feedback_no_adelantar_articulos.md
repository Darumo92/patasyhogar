Cuando el usuario dice "vamos con el artículo de hoy" y la fecha actual NO tiene artículo programado (martes, jueves, fines de semana, o semana de indexación):
- Decir claramente que hoy no toca crear artículo nuevo
- Proponer alternativas: updates SEO a artículos existentes, fixes técnicos, internal linking, indexación, etc.
- NO adelantar el siguiente artículo del calendario

**Excepción:** Si hay artículos de fechas PASADAS que no se completaron (atrasados), esos SÍ se pueden hacer.

**Why:** El usuario quiere respetar el ritmo del plan (Lun/Mié/Vie) y usar los días libres para otras mejoras que no sean crear contenido nuevo.

**How to apply:** Siempre comprobar la fecha exacta contra el calendario en `project_plan_v7_calendario.md` antes de proponer escribir un artículo.
