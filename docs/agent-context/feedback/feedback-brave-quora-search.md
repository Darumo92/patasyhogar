# Regla: Buscar Quora con Brave Search

**Fecha:** 2026-07-10

Para encontrar preguntas de Quora: usar **Brave Search** (`search.brave.com`) con búsqueda del tipo:

```
site:es.quora.com <tema>
```

Ejemplo: `site:es.quora.com bañar perro verano frecuencia`

NUNCA intentar scrapear la búsqueda de Quora directamente (`es.quora.com/search`). No funciona (devuelve página de login, bloquea scraping).

Proporcionar siempre el link de la pregunta de Quora junto con el borrador de respuesta.
