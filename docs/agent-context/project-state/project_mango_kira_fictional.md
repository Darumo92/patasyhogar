Mango (gato europeo naranja) y Kira (perra mestiza) son personajes ficticios creados para humanizar el contenido. El usuario Daniel Ruiz no tiene mascotas reales.

**Por qué importa:** 63 artículos tienen narrativa de primera persona con detalles específicos (veterinaria "Laura", Valencia, aparcamiento adopción, etc.) presentada como experiencia real. Patrón de fake E-E-A-T signals — riesgo con Helpful Content Update.

**How to apply:**
- NO proponer "fotos reales con Mango/Kira" en Fase C — imposible
- En Fase C (junio+): editar artículos para añadir capa verificable (reviews Amazon ES reales, datos etiquetas, comparaciones propias) en vez de más anécdotas personales
- Para artículos nuevos futuros: usar voz editorial ("analizamos", "tras revisar X compradores") en vez de primera persona con mascotas
- Pivote gradual: no borrar todo de golpe (commits masivos = peor throttling)
